My Projects

Here are some projects I've completed during my CS300 Web Development course.

Profile Card - Assignment 1

For Assignment 1, I created a personal profile card using HTML and CSS. The purpose of this project was to practice organizing information and creating a clean, visually appealing layout.

About This Project

I wanted my profile card to be simple and easy to read while still keeping a sense of individuality. I included a profile image, my name, a short biography, and social media links. My goal was to make the information organized and accessible without making the design too complicated.

I started by planning the layout and creating the HTML structure. I used CSS to customize the colors, spacing, fonts, and overall appearance of the card. I also added hover effects to make the links more interactive. Throughout the process, I focused on keeping the design consistent and making the content easy to follow.

One important part of this assignment was learning how HTML and CSS work together. HTML provided the structure of the profile card, while CSS allowed me to control how everything looked. I also worked on making the layout responsive so it could be viewed on different screen sizes.

This project helped me become more comfortable with writing HTML, applying CSS styles, and organizing a webpage. It also showed me how small design decisions can improve the overall appearance and usability of a website.

J Plumbing Website - Assignment 2

For Assignment 2, I created a responsive website for J Plumbing using HTML and CSS. The goal was to design a professional website that would help customers learn about plumbing services and easily find contact information.

About This Project

I wanted the J Plumbing website to look professional while remaining simple and easy for customers to use. I created multiple pages, including Home, Services, About, and Contact. The website included information about drain cleaning, leak repairs, water heaters, and pipe replacement. I also included customer testimonials to help build trust with visitors.

I started by planning the website's structure and organizing the content. I used HTML to create the different pages and CSS to customize the colors, spacing, navigation, and overall layout. I used Flexbox and Grid to organize different sections and make the website responsive.

An important part of this assignment was making sure the website worked on different devices. I worked with mobile, tablet, and desktop layouts and used media queries to adjust the design for different screen sizes. I also tested keyboard navigation to make sure visitors could move through the website without using a mouse.

This project helped me better understand responsive web design, website navigation, and accessibility. It also gave me experience creating a website for a business rather than just a personal webpage. I learned how important it is to consider the needs of visitors when organizing information and designing a website.
